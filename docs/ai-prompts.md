## How It Works

The Vyges SoC Generator takes a declarative specification (`soc-spec.yaml`) and produces
a complete, tape-out-ready SoC. All IP blocks are resolved from the Vyges IP Catalog
(VyCatalog) — the generator fetches metadata, RTL, and integration hints for each IP
automatically. No manual IP cloning or port-list wiring required.

```
soc-spec.yaml  →  Vyges SoC Generator  →  RTL + firmware + constraints + docs + OpenLane configs
                         ↕
                    VyCatalog API
                  (IP metadata + RTL)
```

The specification declares:
- CPU (Ibex RV32IMC), bus (TL-UL), peripherals (UART, SPI Host, PLIC, FFT)
- Memory map (addresses, sizes)
- Timing constraints (50 MHz, sky130 corners)
- Caravel GPIO pin mapping
- Firmware application (sensor demo)

The generator resolves each IP from VyCatalog, reads its `vyges-metadata.json`
(interfaces, parameters, `soc_generator_hints`), and auto-generates: crossbar,
bridge wrappers, address map, firmware headers, timing constraints, block diagram,
OpenLane configs, and Caravel integration (glue module + wrapper).

Each IP carries a `vyges-metadata.json` with:
- Interface declarations (clock, reset, bus protocol, I/O signals)
- Parameters and their defaults
- `soc_generator_hints` for auto-wiring (top module name, bus slave ports, interrupts)
- RTL file list and quality metrics

The generator uses this metadata to compose IPs into a SoC without manual port-list
maintenance — the same metadata that VyCatalog indexes and serves via API.

### About vyges-metadata.json

`vyges-metadata.json` is the Vyges **Silicon IP Nutrition Label** — a standardized,
machine-readable metadata format for semiconductor IP blocks. It captures everything
a SoC integrator needs: interfaces, parameters, bus protocols, integration hints,
verification status, and quality metrics. This metadata format and the tooling that
consumes it (SoC Generator, VyCatalog) are **copyright Vyges Inc.** and **patent pending**.

The format is openly visible in every IP in the [Vyges public catalog](https://github.com/vyges-ip)
— transparency of the label is intentional. The innovation is in how the metadata
drives automated SoC composition: IP discovery, dependency resolution, bus wiring,
bridge generation, firmware header extraction, and constraint generation — all from
a single declarative specification.
